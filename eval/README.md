# Измерение полноты

Команда `python -m eval.score` печатает полноту (recall), точность (precision),
число оценённых выводов и список пропусков.
Эталон и разметка существуют только в `eval/`. Агент их не читает.

Чтобы измерить новый отчёт, сопоставьте каждый эталонный дефект с выводами по двум
условиям. Цитаты указывают на то же место документа. Объяснение описывает тот же дефект.
Для противоречия в выводе нужны обе стороны. Общую рекомендацию за совпадение не считайте.

Сохраните JSON с полем `report_sha256` (SHA-256 точных байтов отчёта) и объектом
`hits`, где ключ — ID эталона, значение — список ID выводов из отчёта. Пропустите
ключи для пропущенных дефектов. Для другого файла передайте `--report` и `--decisions`.
Привязка к хешу исключает повторное использование разметки после новой генерации.

Укажите в массиве `false_positives` ID проверенных ошибочных выводов.
Точность учитывает уникальные ID из `hits` и `false_positives`. Остальные выводы
остаются вне расчёта. Среди них могут быть верные находки за пределами эталона.
Указывайте охват разметки рядом с точностью.
