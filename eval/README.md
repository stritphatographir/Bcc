# Измерение полноты

Команда `python -m eval.score` печатает полноту (recall), точность (precision),
число оценённых выводов и список пропусков.
Эталон и разметка существуют только в `eval/`. Агент их не читает.

Чтобы измерить новый отчёт, сопоставьте каждый эталонный дефект с выводами по двум
условиям. Цитаты указывают на то же место документа. Объяснение описывает тот же дефект.
Для противоречия в выводе нужны обе стороны. Общую рекомендацию за совпадение не считайте.

Сохраните JSON с полем `report_sha256` (SHA-256 точных байтов отчёта) и объектом
`hits`, где ключ — ID эталона, значение — список ID выводов из отчёта. Пропустите
ключи для пропущенных дефектов. Для другого файла передайте `--report` и `--decisions`.
Привязка к хешу исключает повторное использование разметки после новой генерации.
Для группы дефектов засчитывается вывод, который подтверждает хотя бы один конкретный
пропуск или конфликт внутри группы. Команда печатает список пропущенных групп.

Укажите в массиве `false_positives` ID ошибочных или недостаточно подкреплённых выводов.
В `valid_extra` запишите верные замечания с цитатой за пределами эталона.
Они увеличивают число верных выводов для precision. На recall влияют только группы из `hits`.
В `undecided` запишите спорные выводы, для которых нужен дополнительный документ.
Спорные и ещё не рассмотренные выводы исключаются из знаменателя precision.
Указывайте охват рядом с точностью.

В финальном отчёте Gemini оценён 71 вывод. D-036 показывает конфликт
выбора месяца между бизнес-правилом и приёмочным примером (G02). D-037 показывает
конфликт лимита за период с повтором после смены настройки (G01).
Итог — 59 подтверждённых выводов, 12 отклонённых, 27 найденных групп из 30.

`eval/ablation.json` хранит измерения от 27 ноября 2026 на одной сегментации
документа. Для строк «правила», «критики» и «симулятор» использованы выводы
соответствующих этапов до сверки цитат. Для голосования использованы три ответа
на задачу с порогом большинства. Проверка ссылок выполнялась отдельно в обоих
полных профилях. В этом замере она не отбросила ни одного вывода.
